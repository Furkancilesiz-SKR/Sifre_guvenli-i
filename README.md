
# 🛡️ Kalkan - Siber Güvenlik Şifre Analizörü

Kalkan, kullanıcıların şifrelerini siber güvenlik standartlarına göre test eden ve olası bir **Brute Force (Kaba Kuvvet)** saldırısına ne kadar dayanabileceğini matematiksel olarak hesaplayan Python tabanlı bir araçtır.

## ✨ Özellikler
- **Güç Skoru:** 6 farklı kritere göre %100 üzerinden puanlama.
- **Güvenlik Çubuğu:** ANSI renkleri ile görselleştirilmiş terminal arayüzü.
- **Matematiksel Tahmin:** Şifrenin karakter setine göre toplam kombinasyon sayısını hesaplar.
- **Gizlilik:** `getpass` kütüphanesi ile şifre girilirken ekranda görünmez.
